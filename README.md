# 🐙 Odoo Deploy Test — React + Odoo Module

A React.js SPA that runs **locally** (standalone or inside Odoo) **and** deploys to **Odoo.sh** as a native Odoo module.

## ⚙️ How URL detection works

`src/utils/config.js` auto-detects the environment so **zero config is needed** for most cases:

| Running on | `window.location` | Resolved BASE_URL |
|---|---|---|
| CRA dev server (`npm start`) | `localhost:3000` | `http://localhost:8069` (via `proxy`) |
| Odoo local (`localhost:8069`) | `localhost:8069` | `http://localhost:8069` (same-origin) |
| Odoo.sh | `myco.odoo.com` | `https://myco.odoo.com` (same-origin) |
| Custom domain | `app.myco.com` | `https://app.myco.com` (same-origin) |
| Override | `REACT_APP_ODOO_BASE_URL` set | that value |

## 🖥️ Running locally

### Option A — React standalone (no Odoo needed for UI)

```bash
# 1. Install JS deps
npm install

# 2. Copy env file (leave REACT_APP_ODOO_BASE_URL blank to proxy to :8069)
cp .env.example .env

# 3. Start React dev server
npm start
# → http://localhost:3000
# API calls proxy to http://localhost:8069 (configure proxy in package.json)
```

### Option B — Served through local Odoo (recommended for full testing)

```bash
# Step 1 — Build React into the Odoo module's static folder
npm install
npm run build:odoo
# → output lands in odoo_module/static/build/

# Step 2 — Install / update the Odoo module
# Option i: from shell
./odoo-bin -d mydb -u deploy_test_react --stop-after-init

# Option ii: from Odoo UI
# Settings → Apps → search "Deploy Test" → Install

# Step 3 — Open the app
# http://localhost:8069/deploy-test
```

> **Tip**: while iterating on React locally, use `npm start` (Option A).
> Run `npm run build:odoo` only when you need to test the full Odoo-served flow.

## ☁️ Deploying to Odoo.sh

Odoo.sh deploys **via Git push**. It does NOT run `npm install` or `npm run build`,
so you must commit the compiled React build before pushing.

### One-time setup

```bash
# 1. Connect your GitHub/GitLab repo to Odoo.sh (do this in the Odoo.sh UI)
#    https://www.odoo.sh/documentation

# 2. In your Odoo.sh project → Settings → Repositories
#    Make sure the repo root is recognised (the .odooshrc file handles addons path)
```

### Every release (deploy workflow)

```bash
# 1. Build React → outputs into odoo_module/static/build/
npm run build:odoo

# 2. Stage the build (IMPORTANT — build/ must be committed, not gitignored)
git add odoo_module/static/build

# 3. Commit everything
git add -A
git commit -m "feat: update React build + <your change description>"

# 4. Push to your Odoo.sh branch
git push origin main        # or: staging, production — whichever branch Odoo.sh tracks

# Odoo.sh detects the push → installs/updates the module automatically.
# The React app is live at: https://<your-instance>.odoo.com/deploy-test
```

### Environment variables on Odoo.sh

You can set `REACT_APP_ODOO_BASE_URL` as a **build-time env var** in Odoo.sh
(Project → Settings → Environment Variables) if you need to point the React app
at a different Odoo instance. For same-instance usage (the default), leave it blank.

| Command | What it does |

## 🔌 Odoo JSON-RPC endpoints used

| Endpoint | Purpose |
|---|---|
| `/web/webclient/version_info` | Server version + ping |
| `/web/session/authenticate` | Login (session cookie) |
| `/web/session/destroy` | Logout |
| `/web/database/list` | List databases |
| `/web/database/create` | Create database |
| `/web/database/drop` | Drop database |
| `/web/database/duplicate` | Duplicate database |
| `/web/dataset/call_kw` | Generic model CRUD |
| `/deploy-test/health` | Module health check (JSON) |

## 🛠️ Troubleshooting

| Problem | Fix |
|---|---|
| `npm start` can't reach Odoo | Make sure Odoo runs on `:8069`; check `proxy` in `package.json` |
| `/deploy-test` shows "Build missing" | Run `npm run build:odoo` then restart Odoo |
| CORS errors on Odoo.sh | App is same-origin — CORS shouldn't appear. If it does, check `REACT_APP_ODOO_BASE_URL` |
| Module not found after push | Check `.odooshrc` points to `odoo_module`; verify `__manifest__.py` is valid |
| DB operations fail | Verify you're using the correct Odoo master password |
